# Draw Your Sound

Експериментальний електронний музичний інструмент у браузері: малюйте звук на частотному полотні або пишіть ноти в Piano Roll — обидва режими працюють з одним проєктом, одним аудіорушієм і однією часовою шкалою. Працює в Safari на iPhone і в браузерах на Mac, офлайн, без збірки (чистий ES-модулі, придатно для GitHub Pages).

## Режими

- **Малювати (Free Draw)** — X = музичний час (долі), Y = частота 20–16 000 Гц на логарифмічній осі. Уся площина полотна є робочою (немає «мертвих» зон зліва/справа). Лінію можна малювати в будь-який бік: час визначається позицією, а не напрямом чи швидкістю руху пальця. Режими обробки: **Smooth**, **Natural**, **Sharp / Step** з регулятором інтенсивності; необов'язкова прив'язка до ладу. Лінії можна вибирати, переміщати, дублювати, віддзеркалювати, перестилізовувати й стирати.
- **Ноти (Piano Roll)** — створення нот кліком/дотиком і протяжкою, переміщення, зміна довжини за правий край, виділення рамкою, групові дії, копіювання/вставлення в точку, дублювання, Undo/Redo, горизонтальний і вертикальний zoom (колесо, трекпад, pinch), прокрутка, навігація по октавах, сітка 1/4–1/32 від BPM, підсвічування ладу, велика зона наведення для пальця.
- **Ритм** — драм-секвенсор: Kick, Snare, Clap, Hat closed/open, Perc; довжина кожної доріжки своя (поліметр); акцент/тихо/вимк.; пресети й мутація.
- **Мікс** — гучність, Mute/Solo, спектр-аналізатор, налаштування доріжки (інструмент, хвиля, ADSR, фільтр, drive, панорама, reverb/delay) і майстра (reverb, delay, chorus/ширина, drive, компресор + лімітер).

## Клавіатура (Mac / ПК)

`Пробіл` грати/стоп · `⌘Z` / `⇧⌘Z` (`Ctrl+Y`) undo/redo · `⌘C/X/V/D/A` копіювати/вирізати/вставити/дублювати/виділити все · `Delete` видалити · стрілки — зсув нот (`Shift` — октава/такт) · `1–4` режими · `D/S/E` інструменти · `⌘S` зберегти · колесо/двопальцева прокрутка — навігація, `⌘`/`Ctrl`+колесо (або pinch на трекпаді) — zoom по часу, `Alt`+колесо — zoom по висоті.

## Архітектура

| Модуль | Роль |
| --- | --- |
| `js/coords.js` | **Єдина** математика: пікселі ↔ час (долі) ↔ висота (MIDI) ↔ частота; `Viewport`, сітка, snap |
| `js/model.js` | Модель композиції, валідація, міграція старих проєктів |
| `js/store.js` | Стан + Undo/Redo (один жест = один запис) |
| `js/curve.js` | Згладжування/ступені ліній, семплювання кривої в часі |
| `js/audio.js` | Аудіорушій: голоси, інструменти, ефекти, лімітер, ударні |
| `js/transport.js` | Транспорт і планувальник за годинником аудіо (lookahead), live-редагування |
| `js/freedraw.js`, `js/pianoroll.js`, `js/drumseq.js` | Редактори |
| `js/gestures.js` | Миша / дотик / pinch / трекпад |
| `js/ops.js` | Чисті операції над нотами та лініями (перекриття, копіювання, мутація) |
| `js/storage.js`, `js/export.js` | Автозбереження (два слоти), JSON/WAV/MIDI |
| `js/app.js` | Композиція застосунку й інтерфейс |

Час усюди зберігається в **долях** (чвертях), висота — у MIDI; нормалізовані координати чи секунди в даних не використовуються. Тому BPM, сітка й Piano Roll не можуть розійтися.

## Формат проєкту

`.dys.json`: `{ format: "draw-your-sound", version: 2, project: {…} }`. Імпорт перевіряє структуру, обмежує значення й підтримує файли старої версії (нормалізовані `lines`/`notes`).

## Розробка та тести

```bash
npm install
npx playwright install chromium webkit
npm test            # unit (node:test) + e2e (Chromium і WebKit)
python3 -m http.server 8000   # відкрити http://localhost:8000
```

Деталі плану тестування та чесний перелік неперевіреного — у [TESTING.md](TESTING.md).
